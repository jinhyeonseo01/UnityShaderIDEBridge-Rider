# Changelog

All notable changes to this package are documented in this file.

- Initial Bridge+Diagnostics implementation for Unity 6.3.
- Added Rider-focused shader/hlsl open bridge:
- `.shader`, `.compute`, `.cginc`, `.glslinc`, `.hlsl`, `.cg`
- Added menu actions:
- `Tools/Clerin/Shader IDE Bridge/Open In Rider`
- `Tools/Clerin/Shader IDE Bridge/Validate Rider Shader Setup`
- Added Project Settings section:
- `Project/Clerin/Shader IDE Bridge`
- Added EditMode tests for extension filtering and Rider argument generation.
- Added NuGet shared core utility scaffold.
- Added CI and release workflow scaffolding for UPM/OpenUPM/NuGet.
